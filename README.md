# Darija Drills

Static site for drilling Moroccan Arabic (Casablanca / Rabat Darija): verb conjugation, possessives,
gender and plurals, in arabizi and Arabic script. No build step for the site itself; GitHub Pages
serves the repo root as is (Settings → Pages → Deploy from branch → `main` / root).

## Run locally

Pages load JSON with `fetch`, so open them through a server, not `file://`:

```sh
python3 -m http.server 8765
```

## Layout

```
index.html verbs.html match.html nouns.html prepositions.html numbers.html words.html vocab.html dictionary.html rules.html
assets/                shared CSS and ES modules (common.js, quiz.js, one module per page)
data/verbs.json        706 verbs with full past and present paradigms (generated)
data/nouns.json        nouns and adjectives with possessive, dyal, definite and plural forms (generated)
data/prepositions.json prepositions with pronoun endings, verb collocations and idioms (generated)
data/words.json        time and place words and phrases (the "Time & place" page): today, week, left, north (generated)
data/examples/<id>.json  example sentences per verb, one file each (generated by Claude)
data/doda.json         986 everyday nouns in 12 topics, from DODa (the "Vocabulary" page; generated)
data/spelling.json     one spelling per word, from corpus counts (generated; see docs/spelling.md)
data/raw/              hand-edited inputs
scripts/               generators
docs/spelling.md       the spelling convention and how it is enforced
tests/                 python3 -m unittest discover tests
```

## Data

Verbs come from the Peace Corps Morocco *Moroccan Arabic* (2011) verb glossary (pp. 163–192),
which lists each verb with its "I" present and past form.

1. `scripts/extract_glossary.py <pdf>` pulls the glossary into `data/raw/pc_glossary.tsv`
   (needs `pypdf`: `uv run --with pypdf python scripts/extract_glossary.py ...`).
2. `scripts/build_verbs.py` sorts each verb into a type (regular, hollow, ends in a vowel,
   doubled, hamza...), places the schwa the book leaves out, converts to arabizi, spells the
   Arabic, and writes all 8 persons for past and present to `data/verbs.json`.
   The future is built in the browser (ghadi + present without ka-).
   - `data/raw/verb_notes.json`: corrections, exclusions and better glosses, keyed by the book's spelling.
   - `data/raw/verb_tags.json`: levels (Starter, Everyday; everything else is Extended) and topics.
3. `scripts/build_nouns.py` turns `data/raw/nouns.json` into `data/nouns.json`.
4. `scripts/build_examples.py` writes example sentences to `data/examples/<id>.json`. It runs headless
   Claude Code (`claude -p`, Sonnet 5.5) on the logged-in plan and keeps the raw output in
   `data/raw/examples/`. A stopped run resumes where it left off; `--ids kteb,chaf --redo` rewrites
   single verbs. Sentences that lose the exact verb form or mix scripts are dropped.
   - default: three sentences per verb (past, present, future, each with a different person), 20 verbs per call.
   - `--full`: every tense × person × positive/negative, 48 sentences per verb, 3 verbs per call.
     Takes levels 1 and 2 unless `--level` or `--ids` is given. Verbs without a full set keep the three.
5. `scripts/build_prepositions.py` turns `data/raw/prepositions.json` into `data/prepositions.json`.
6. `scripts/build_words.py` turns `data/raw/words.json` into `data/words.json`. These words are not from the book;
   they are invariable, so each has just a spelling, a gloss and optionally a note and an example.
7. `scripts/build_doda.py` turns the DODa semantic categories in `data/raw/doda/` into `data/doda.json`: it picks the
   spelling people write most, rewrites it in the site's letters and skips words the site already teaches.
   `data/raw/doda_notes.json` (optional) holds `drop` and `fix` entries keyed by DODa's first spelling.
8. `scripts/spelling.py` picks one spelling per word from how often Moroccans write each one
   (`data/raw/spelling_counts.json`, hand-made choices in `data/raw/spelling.json`) and writes `data/spelling.json`.
   Steps 3 to 7 rewrite their arabizi to those spellings. See [docs/spelling.md](docs/spelling.md).

After editing anything in `data/raw/`, rebuild and test:

```sh
python3 scripts/build_verbs.py && python3 scripts/spelling.py && python3 scripts/build_nouns.py && python3 scripts/build_prepositions.py && python3 scripts/build_words.py && python3 scripts/build_doda.py && python3 -m unittest discover tests
```

Spelling: arabizi with 3 = ع, 7 = ح, ch = ش, gh = غ, kh = خ, q = ق, and one spelling per word everywhere; see [docs/spelling.md](docs/spelling.md).
Typed answers ignore schwa, doubled letters and spaces, and also accept the book's letters
(š x ġ ع н).
