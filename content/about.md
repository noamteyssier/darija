This site is both a reference and a learning tool that I've built to help myself learn and practice Darija away from Morocco.
It is incomplete but as I continue to learn and improve my own skills, I will continue to add content and improve the site.

## Sources and Dialects

I've developed it focusing around Moroccan Arabic as spoken in Casablanca.
The sources for the vocabulary and grammar rules come from a few different sources I've pulled together from across the internet.
Many of the examples in the site are LLM-generated and may not be perfect, but hopefully they are helpful as a starting point for seeing the conjugation of words in different contexts.

## Repetition and Configuration

A key goal for the site is to provide drills around structured repetitions that can be configured.
You can subset the drills to focus on specific topics or grammar rules and repeat them until you feel comfortable with the material.

## Canonical Spelling

A focus of mine in developing the site was to standardize the spelling conventions of the arabizi *within the site*.
Because Darija is a spoken language without canonical spelling each person uses their own spelling conventions.
However the arabic script used is often more consistent than the latin script used to write the text so this site attempts to follow a consistent arabic script -> latin script translation.
This is mostly enforced programmatically and checked by the CI as new examples and words are introduced, but it is still a work in progress.
