The site works offline once you have opened it with a connection. Install it to get an icon and a full-screen app.

- **iPhone or iPad:** open it in Safari, tap Share, then Add to Home Screen. Other iOS browsers can only save a shortcut.
- **Android:** in Chrome, open the menu and tap Install app.
- **Desktop:** in Chrome or Edge, click the install icon in the address bar.

Updates arrive by themselves: after a new version is published, the second time you open the app shows it.
